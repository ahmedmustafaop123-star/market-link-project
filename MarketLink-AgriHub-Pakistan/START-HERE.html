⚠️ Important

http://localhost:3000 only works after you start the server (steps below) and while its black window stays open. Also: extract this folder from the zip first, because it can't run from inside the zip.

▶️ Run the website on this PC (4 steps)

  1. Install Node.js 20 LTS or newer from nodejs.org (one time, default options).
  2. Windows: double-click start-windows.bat  ·  Mac/Linux: open Terminal here and run bash start.sh
  3. First run installs & builds (3-6 minutes). Wait for ✅ MarketLink is running!
  4. Your browser opens http://localhost:3000 automatically. Keep the window open; press Ctrl+C to stop.

No PostgreSQL needed: a built-in database is created automatically in the .data folder, with Pakistani demo data.

🗄️ Connect PostgreSQL on your laptop (optional)

  1. Install PostgreSQL with pgAdmin from postgresql.org/download. Remember the postgres password; keep port 5432.
  2. Open .env in this folder (copy .env.example if missing) and set:
    DATABASE_URL=postgresql://postgres:YOUR_POSTGRES_PASSWORD@127.0.0.1:5432/app_db
  3. In a terminal here run node scripts/check-db.cjs --create, then run start-windows.bat again. The website creates tables on the first visit.
  4. In pgAdmin open Databases → app_db → Schemas → public → Tables and refresh. You can now inspect users, crops_inventory and orders_logistics.

Existing built-in data stays in .data/pglite but does not move into the new PostgreSQL database automatically. The cloud preview is a separate database.
